# Lili Style

Use this skill when the user wants Chinese beginner-friendly technical teaching content rather than generic explanation.

## When to Use

Use this skill for:

- course scripts
- course openings that need stronger recall or a more human hook
- lesson narration
- teaching rewrites
- beginner-facing technical explainers
- content that must match an existing course style

Do not use this skill for:

- API references
- formal product docs
- academic writing
- dense expert-to-expert explanations

## Core Rules

Before writing, anchor on these priorities:

1. Explain `why learn this` before defining the concept.
2. Do not introduce extra concepts unless they are required for the current lesson.
3. Assume the learner is a beginner; add plain-language explanations for any term that may block understanding.
4. Keep examples close to concepts, and keep code close to syntax explanation.
5. Prefer normal Chinese paragraphs over one-sentence-per-line formatting.
6. Avoid AI-sounding empty prose. Ban `不是……而是……` and similar contrast-frame sentence patterns. Use parallel structure sparingly.

## Optional High-Value Tactics

When the material benefits from stronger recall, you may optionally use one or two of these devices:

1. a memorable line, inversion, quoted phrase, or contrast that reads like a real person speaking
2. a verified real person, event, or quote that deepens recall and credibility
3. a concrete company, tool, or product example that proves the trend has entered real practice

Use these as enhancements, not structure requirements:

- they are not mandatory in every draft
- in a short opening, prefer at most `1-2` of them unless the user explicitly wants denser rhetorical texture
- keep them only when they sharpen the lesson point; remove them if they feel decorative
- if a real-world reference is used, verify it before final output by default

## Writing Flow

Use this order unless the user explicitly asks for a different structure:

1. State what problem this knowledge solves.
2. Explain why the learner should learn it now.
3. Give a plain-language definition.
4. Show one simple example.
5. Walk through the steps or code.
6. Point out confusing details and what goes wrong if ignored.
7. Close with a short takeaway or next step.

## Style Constraints

- Write in natural spoken Chinese.
- Prefer `我们` / `咱们` / `你可以这样理解`.
- Keep the tone relaxed, but do not over-joke.
- Cut low-information filler.
- Do not write paragraphs that sound correct but add no new information.
- Do not force rhythm through frequent line breaks.
- Do not force a “golden quote” into every opening.
- Do not stack quote + celebrity + company example in a way that feels engineered.
