# 开发门禁

## 定位

本文件只负责判断“本轮任务触发哪些规则 ID”。规则正文以 `references/rule-registry.md` 为唯一来源，不在本文件重复。

## 使用方式

1. 先根据用户请求和项目证据判断任务类型。
2. 按下方门禁表列出触发规则 ID。
3. 执行规则时读取 `references/rule-registry.md` 对应 ID。
4. 验收时到 `references/acceptance.md` 填写结论和证据。

## 基础门禁

| 触发条件 | 规则 ID |
| --- | --- |
| 任何非平凡调研、开发、修复、验证 | `CORE-001` |
| 需要确定本轮范围、避免顺手改动 | `CORE-002` |
| 新增接口、查询、方法、字段、页面动作、组件或业务能力 | `CORE-003` |
| 非平凡开发、修复、跨文件改动 | `CORE-004` |
| 需要声明验证、未验证、无法证明 | `CORE-005` |
| 工作区已有改动、越界文件、恢复或回滚风险 | `CORE-006` |
| 修改本 skill 规则、模板、门禁、验收或清单 | `ARCH-001` |

## 契约和后端门禁

| 触发条件 | 规则 ID |
| --- | --- |
| 前后端 API、字段、分页、筛选、排序、导入导出、错误码、权限发生变化 | `CONTRACT-001` |
| 列表、弹窗选择表、明细表或子表展示金额列或时间列并需要用户排序 | `SORT-001` |
| 修改 Controller、Service、Mapper、业务校验、事务、并发、主子表同步 | `BACKEND-001` |
| 修改生产 Java 文件 | `JAVA-001` |
| 新增或调整业务错误码 | `ERROR-001` |
| 涉及代码生成、CRUD scaffold、单表、树表、主子表模板生成 | `CODEGEN-001` |

## 前端门禁

| 触发条件 | 规则 ID |
| --- | --- |
| 新增或修改 Vue 页面、列表页、弹窗、表单、详情、明细组件 | `FE-PAGE-001` |
| 页面包含业务数据表格 | `FE-TABLE-001` |
| 表格包含操作列或行级业务按钮 | `FE-ACTION-001` |
| 页面包含主表或主列表业务数据表格且需要用户调整列可见性 | `FE-COLUMN-001` |
| 查询区、筛选项、表单字段或弹窗选择条件涉及其它表 ID | `FE-FK-001` |
| 表格展示金额、单价、总额、税额、货值、成本、日期或时间列 | `SORT-001` |
| 页面展示、解析、筛选、默认、回显、提交、比较、排序业务时间 | `FE-TZ-001` |
| 页面包含 `DatePicker`、`TimePicker`、日期范围、时间范围、响应式日期范围组件或移动端日期弹层 | `FE-DATE-001` |
| 新增或修改任意前端页面、弹窗、表单、表格或工具栏 | `FE-MOBILE-001` |
| 新增或修改弹窗、表单、表单校验、保存动作 | `FE-FORM-001` |

前端页面一般至少触发 `FE-PAGE-001` 和 `FE-MOBILE-001`。包含业务表格时，同时触发 `FE-TABLE-001`；有操作列时触发 `FE-ACTION-001`；有主表列显示时触发 `FE-COLUMN-001`；涉及其它表 ID 时触发 `FE-FK-001`。

## 停止条件

出现以下情况时停止说明，不继续编辑：

- 当前切片不清。
- 无法确认允许修改面或禁止修改面。
- 触发规则 ID 无法确定。
- SQL 主落点、权限拥有方、数据拥有方或状态拥有方找不到。
- 继续会覆盖用户已有改动。
- 用户未授权高成本或高副作用验证。
